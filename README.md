<h1>Описание</h1>
Данное приложение - сервис для описания мероприятий (от выставки до похода в кино) и сбора компании для участия в нем. 

<h2>API проекта</h2>

<h2>Внутренняя структура</h2>
Приложение организовано с использованием микросервисной архитектуры.

Кроме инфраструктурных сервисов (Eureka, ConfigServer, Gateway) приложение содержит сервер статистики и основные сервисы приложения

<h3>Сервисы приложения:</h3>
1. user-service - сервис администрирования пользователей
2. event-service - сервис для ввода, редактирования и просмотра событий
3. request-service - сервис для работы с заявками на участие в событиях
4. comment-service - используется для создания и просмотра комментариев о событиях

Взаимодействие между основными сервисами осуществляется через Open Feign.
